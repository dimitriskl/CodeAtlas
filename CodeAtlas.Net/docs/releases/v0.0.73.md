# CodeAtlas 0.00.73

CodeAtlas indexes C# solutions with Roslyn and exposes the saved semantic index through the CLI and a local stdio MCP server.

## MCP tools

- `find_symbol`: exact symbol and overload lookup.
- `search_symbols`: ranked name/purpose search over saved evidence.
- `find_references`: static method references, with kind/project filters and snapshot-bound paging.
- `index_status`: generation freshness and coverage.
- `coverage`: supported analysis scope and exclusions.
- `index`: build and publish the session solution's index.

The server stays warm, reloads a newly published generation and refuses stale tracked inputs. Malformed request lines receive errors while the session continues. Reference kind `invocation` identifies the actual callee; rebuild older indexes after upgrading.

## Install

Install a suitable .NET SDK; the tool runs on .NET 10. Download `CodeAtlas.Tool.0.0.73.nupkg` into a local package directory and verify it against `SHA256SUMS.txt`.

```powershell
dotnet tool install CodeAtlas.Tool --tool-path C:/Tools/CodeAtlas --add-source C:/Downloads/CodeAtlas --version 0.0.73
C:/Tools/CodeAtlas/codeatlas.exe --version
C:/Tools/CodeAtlas/codeatlas.exe index --solution C:/Projects/<project_name>/<project_name>.slnx
C:/Tools/CodeAtlas/codeatlas.exe mcp --solution C:/Projects/<project_name>/<project_name>.slnx
```

Use suitable absolute paths and `codeatlas` on Linux/macOS. Existing users can use `dotnet tool update` with the same package directory and version.

The [demo](https://github.com/dimitriskl/CodeAtlas/blob/v0.0.73/CodeAtlas.Net/docs/DEMO.md) uses the standalone `package-smoke.py` client and `package-fixture.zip` assets to install, index and inspect references locally. [Client configuration](https://github.com/dimitriskl/CodeAtlas/blob/v0.0.73/CodeAtlas.Net/README.md#quick-start-install-index-connect), [query contracts](https://github.com/dimitriskl/CodeAtlas/blob/v0.0.73/CodeAtlas.Net/docs/QUERY-CONTRACT.md) and [output locations](https://github.com/dimitriskl/CodeAtlas/blob/v0.0.73/CodeAtlas.Net/docs/USAGE.md#where-is-the-output) describe normal use.
